# Den is one household's library, not a public catalogue. Nothing here is meant to be crawled,
# indexed, archived or used as training data, and there is nothing to find: every page is drawn
# from a library this visitor holds the key to. A crawler gets the empty shell and nothing else.
#
# den-edge sends `X-Robots-Tag: noindex, nofollow, noarchive, noimageindex` with the app's HTML
# too. This file asks crawlers not to fetch; that header tells the ones that fetch anyway not to
# keep what they got.

User-agent: *
Disallow: /

# no poster. They render previews; they do not publish a searchable index.
